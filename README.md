# 🍽️ Fine Dining Reservation Analytics

## Overview
This project analyzed reservation trends, cancellations, and operational efficiency for a fine dining restaurant environment.

## Tools Used
- R
- Power BI
- Excel

## Key Features
- Predictive modeling for expected covers
- Cancellation trend analysis
- Revenue impact calculations
- Dashboard reporting

## Key Findings
- Weekend reservations showed significantly lower cancellation rates
- Certain weekdays consistently underperformed expectations
- Operational staffing could be optimized using forecasted cover counts
